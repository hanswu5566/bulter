
  🏆 Phase 1: MVP 里程碑 (docs/mvp.md)
  目標：建立「信任驗證」的核心價值，完成從找房、媒合到實地看房存證的閉環。


  Milestone 1: 數據與身分地基 (The Foundation)
   * 身分驗證：整合 Google OAuth，實作房客/房東雙角色切換。
   * 資料結構：實作支援台日市場（租補、禮金、保證人）的房源 Schema。
   * 591 搬移工具：實作 URL 爬蟲解析與 Gemini Vision OCR 截圖填表，解決冷啟動房源不足問題。


  Milestone 2: 意圖採集與智慧搜尋 (Discovery)
   * Butler AI Onboarding：透過動態對話採集租客生活習慣，提取結構化標籤。
   * 混合搜尋引擎：地圖 PIN 點搜尋 + 傳統條件過濾（租金、區域、政策標籤）。
   * AI 適配分析：顯示 Match Score，並由 Butler 提供「推薦理由」與「潛在風險」點評。


  Milestone 3: 溝通媒合與預約系統 (Engagement)
   * 內建聊天系統：雙方即時溝通，支援 Gemini 自動語系翻譯。
   * 自建預約系統：房東管理時段，租客一鍵預約。媒合成功後自動生成「看房提醒包」。


  Milestone 4: 信任存證與報告生成 (Verification)
   * 細緻看房引導：手動檢查清單（水壓、噪音、安全動作提示）。
   * 反應式 AI 存證：有疑慮時才拍照，自動標註時間、地點與防偽浮水印。
   * 結案報告：Gemini 總結實勘事實，生成 PDF 存證，並將物理數據回流更新房源資料。

  ---


  🚀 Phase 2: 交易深化與自動化 (Iteration 1)
  目標：將產品從「工具」轉向「交易中心」，提升轉化效率。


   * Milestone 5: 數位合約與電子簽章
       * 整合電子簽章 API。
       * 自動將「看房存證報告」作為合約附件，具備法律效力。
   * Milestone 6: Butler 行動助手
       * 根據預約時間主動推播交通指南、看房注意事項。
       * AI 自動跟進看房後的意願，加速媒合反饋。

  ---


  🌐 Phase 3: 生態系擴張 (Iteration 2)
  目標：解決深層市場結構問題，建立競爭壁壘。


   * Milestone 7: 日本市場保證體系介接
       * Trust Profile 數據與日本保證公司 API 對接。
       * 初期費用分期或代償保險方案整合。
   * Milestone 8: IoT 高齡與居住安全
       * 針對日本高齡租客，整合智慧電表異常偵測（安否確認）。
       * 一鍵投保「孤獨死損失險」，消除房東偏見。
   * Milestone 9: 入住後維修管家
       * 反應式報修存證：租期中損壞拍照，AI 比對「入住前現況」判定責任歸屬。
