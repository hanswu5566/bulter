# Butler. 專案開發指南 & 現況摘要 (2026-02-19)

本文件旨在記錄專案當前的技術狀態、已實現的功能邏輯，以及後續開發的規範建議。

## 1. 核心產品定位
- **名稱**：Butler. (AI 智慧租屋管家)
- **核心價值**：利用 AI (Gemini) 簡化房東上架流程，並為房客提供深度實勘與匹配建議。

## 2. 已實現功能摘要

### A. AI 智慧房源匯入 (591 整合)
- **精準爬蟲**：實作於 `src/lib/scrapers/taiwan-591.ts`。能自動擷取 591 網頁中的 `og:image`、`window.__NUXT__` 數據及原始房源照片，排除了廣告與推薦物件的干擾。
- **解析邏輯**：使用 `Gemini-2.0-flash` 進行結構化解析。
- **兩階段照片處理**：
    1. **預覽階段**：匯入時僅顯示 591 原始網址（加上 `no-referrer` 政策以防盜連），節省空間。
    2. **存檔階段**：只有當使用者點擊「確認發布」後，後端才會將照片下載並轉存至 GCS。

### B. 圖片最佳化與雲端儲存
- **轉存機制**：實作於 `src/lib/storage.ts` 中的 `uploadFromUrl`。
- **最佳化處理 (Sharp)**：
    - **格式轉換**：統一轉為 **WebP** 以極大化節省空間。
    - **尺寸限制**：最大寬高限制為 **1200px**。
    - **壓縮品質**：固定為 **80%**。
- **生命週期管理**：刪除房源紀錄時，系統會同步呼叫 `deleteFiles` 徹底清理 GCS 中的對應檔案。

### C. 互動式地圖
- **技術棧**：使用官方 `@vis.gl/react-google-maps` 元件。
- **環境變數**：必須使用 `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` 以供前端調用。
- **目前狀態**：支援縮放、平移與房源標記（Marker）。

### D. UI/UX 與 導覽階層
- **身分敏感導覽**：導覽列會根據 `LANDLORD` 或 `TENANT` 身分切換工作區（我的房源 vs 實勘報告）。
- **視覺語言**：採用高質感毛玻璃效果（Backdrop Blur）、圓角卡片設計、以及清晰的行動導向按鈕（Call-to-Action）。
- **i18n 友善**：透過 Middleware 自動處理語系跳轉，確保 `/listings` 類型的網址能自動導向至 `/zh-TW/listings`。

## 3. 環境變數規範 (.env)

| 變數名稱 | 用途 | 是否需要 NEXT_PUBLIC_ |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | AI 解析與 Butler 建議 | 否 (伺服器端) |
| `GCP_PROJECT_ID` | Google Cloud 專案識別 | 否 |
| `GCS_BUCKET_NAME` | 圖片儲存桶名稱 | 否 |
| `GCP_CLIENT_EMAIL` | GCS 上傳權限 Email | 否 |
| `GCP_PRIVATE_KEY` | GCS 上傳權限私鑰 | 否 |
| `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` | 瀏覽器載入 Google Maps | **是** |

## 4. 當前待辦與未來擴充方向
1. **經緯度儲存**：目前地圖標記為隨機分佈，未來需在房源存檔時，透過 Google Geocoding API 將地址轉為座標存入資料庫。
2. **編輯功能**：已預留「編輯」入口，需實作完整資料帶入表單的修改邏輯。
3. **實勘流程接通**：目前實勘報告為靜態或半成品，需整合相機拍照並自動由 AI 標註缺陷的功能。
4. **即時聊天**：Butler 的聊天功能可進一步與房源數據庫連動，提供更精準的帶看建議。
